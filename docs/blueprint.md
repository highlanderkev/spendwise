# **App Name**: SpendWise

## Core Features:

- Expense Input: Allow users to input their expenses, specifying the amount and the category.
- Expense Summary: Display a summary of expenses, broken down by category, for a specified time period.
- Budget Setting: Enable users to set a monthly budget for each expense category.
- Budget Comparison: Visually compare the actual spending against the set budget for each category.
- AI Spending Tips: Use an AI tool to analyze spending patterns and provide personalized tips for saving money.

## Style Guidelines:

- Primary color: Teal (#008080) for a sense of calm and financial stability.
- Secondary colors: Light gray (#F0F0F0) for backgrounds and muted elements.
- Accent: Green (#32CD32) for positive indicators (e.g., savings).
- Clean and modern fonts for easy readability on all devices.
- Simple and intuitive icons to represent expense categories.
- Clean and well-organized layout for easy navigation and data visualization.
- Subtle animations for transitions and user interactions to enhance the user experience.

## Original User Request:
an app for personal finance that tracks all spending
